# BreakPoint User Guide

## Overview
BreakPoint is a web platform where participants solve vulnerable lab simulations and submit tokens to earn score and progress.

## Main Navigation
- `Dashboard`: Your summary, score, completion status, active attempts, and quick submit.
- `All Labs`: Browse available labs, see difficulty, score, and lock/completion state.
- `Attempts`: View attempt history and per-lab attempt statistics.
- `Profile`: View your account info.
- `Leaderboard`: See participant rankings.
- `Documentation`: This usage guide.

## Participant Workflow
1. Register an account and log in.
2. Open `All Labs` and pick an available lab.
3. Start an attempt.
4. Analyze the lab and discover the token.
5. Submit token from lab page (or quick submit if exactly one active attempt exists).
6. If correct, gain score and mark lab completed.
7. If wrong, attempts remaining decreases (maximum 3).

## Lab Access Rules
- Some labs are locked until you reach required EXP.
- Completed labs are marked and cannot be repeated for extra scoring.

## Attempts and Hints
- Each attempt allows up to 3 token submissions.
- Hints are limited and tracked.
- Attempt status can be `in-progress`, `successful`, or `failed`.

## Progress and Ranking
- Dashboard shows completion %, score, badge progress, and active attempts.
- Attempts page shows all attempts and per-lab summaries.
- Leaderboard ranks participants by score.

## Admin Usage (Admin Role)
- Admin pages are available from admin sidebar.
- Admin can create/edit/delete simulations.
- Edit mode pre-fills current simulation data into the form.
- Admin can manage users, monitor submissions, view participant progress, and check platform activity.

## Tips
- Start with lower difficulty labs to build EXP.
- Read lab descriptions before using hints.
- Use Attempts history to improve strategy.
